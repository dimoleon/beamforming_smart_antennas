## Ειδικές Κεραίες
### Αλγόριθμοι Μορφοποίησης Δέσμης Στοιχειοκεραιών
#### NSB

Για να τρέξετε τον κώδικα εγκαταστείστε το εργαλείο `uv` σύμφωνα με τις οδηγίες [εδώ](https://docs.astral.sh/uv/getting-started/installation/). 
Έπειτα, μέσα στον φάκελο της εργασίας τρέξτε τις παρακάτω εντολές:
```
uv sync
uv run src/main.py
```
